One funny single-line one-star review, written by a house cat about its
human, for the make.fun bounty "Make the AI Judge Laugh: Cat Reviews Its
Human".

## Run

```sh
node main.ts
```

It writes the review to `/output/entry.txt` (one line, 122 characters,
well under the 200-character limit). Node 22, standard library only, no
network access, deterministic.
